# Beecrowd | Python

Repositório dedicado à resolução de exercícios usando python na plataforma **Beecrowd**.

## 🚀 Sobre o Beecrowd
O [Beecrowd](https://judge.beecrowd.com/pt) é uma das maiores plataformas de treinamento em programação e algoritmos do mundo. Ela oferece uma lista problemas que ajudam desenvolvedores a aprimorar suas habilidades em diversas linguagens e tecnologias.

## 💻 Usando Python
Os exercícios nesta categoria exploram a sintaxe limpa e as poderosas estruturas de dados do Python, focando em:
* **Entrada e Saída:** Manipulação de `input()` e formatação de strings (`f-strings`).
* **Estruturas de Dados:** Uso eficiente de `lists`, `tuples`, `dictionaries` e `sets`.
* **Processamento de Dados:** Métodos de string (`split`, `join`, `strip`) e conversões de tipos.
* **Lógica de Programação:** Condicionais, laços de repetição e compreensão de listas (*list comprehensions*).

## 📁 Estrutura do Repositório
Cada arquivo `.py` está nomeado com o número do respectivo problema na plataforma para facilitar a localização, assim como a pasta localizando a categoria onde ele se encontra.

Exemplo: `1001.py` refere-se ao desafio [Iniciante > 1001 - Extremamente Básico](https://judge.beecrowd.com/pt/problems/view/1001).
